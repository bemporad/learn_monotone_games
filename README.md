# Learn Monotone Games
A Python library to learn parametric monotone Nash equilibrium (NE) problems from data,
by either direct learning of the NE problem from samples of the agents' costs, or inverse learning of surrogate agents' costs from samples of their best responses. 

This code has been used to generate the results of Section 6 in the paper:

[1] A. Bemporad, T. Tatarenko, "Learning Parametric Monotone Games," arXiv preprint 2609.02494, 2026, https://arxiv.org/abs/2609.02494. 

Make sure you `pip install nashopt` and `pip install mpfit` to their latest version.
